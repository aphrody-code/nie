# Desktop frontend owner

This directory owns Inacord's desktop React presentation inside the common `nie-web`
frontend. `DesktopHost.tsx` composes the existing theme, error boundary and `App.tsx`.
The common `src/main.tsx` mounts either this adapter or `BrowserHost.tsx`; the Vite
`#nie-host` alias chooses the target at build time.

- `components/` contains desktop windows, Explorer, editors and tools.
- `lib/` contains desktop bindings and compatibility adapters. Shared decoding and domain
  logic remain in their Rust or workspace library owners.
- `lib/bindings.ts` is generated by the `inacord` package in the root Rust workspace.
- `styles.css` explicitly scans this directory and both shared UI packages.
- `apps/inacord/public/` remains the desktop public-asset source. Absolute font and sprite
  URLs retain their existing identities through the desktop Vite `publicDir`.

`apps/inacord/src/App.tsx`, `DesktopHost.tsx` and `main.tsx` are compatibility entrypoints.
They delegate here or to the common mount and contain no duplicate application logic.
The native backend remains under `apps/inacord/src-tauri`.

`apps/nie-web/tsconfig.desktop.json` owns desktop TypeScript settings and the `@/*` alias.
The browser and desktop use separate typecheck entry sets because their host bindings differ;
both consume the same reusable UI libraries. `apps/inacord/tsconfig.json` preserves the old
command entry by extending the desktop configuration. Existing package scripts select the
shared Vite root and desktop mode, with output in `apps/nie-web/dist-desktop`.

The relocation is a source ownership change. It does not establish successful builds,
interface fidelity or native/browser behavior equality; those require the gates in `PLAN.md`.
